# Pro Proposal Page

A romantic animated web page for sharing a heartfelt “Will You Be Mine?” message. The experience includes a dreamy starry background, floating hearts and petals, animated sections, a playful no-button interaction, and a celebration screen when the user says yes.

## Features

- Animated landing section with glowing star effects
- Scroll-triggered timeline story cards
- Elegant romantic styling with glassy panels and shimmer effects
- Interactive buttons with playful movement and celebration animations
- Background music and sound effects
- Simple Express server for serving the app locally

## Project Structure

- index.html — main front-end experience
- server.js — Express server for local hosting
- public/ — static assets and supporting files
- package.json — dependencies and scripts

## Requirements

- Node.js
- npm

## Installation

```bash
npm install
```

## Run Locally

```bash
npm start
```

Then open:

```text
http://localhost:3000
```

## Scripts

- npm start — starts the Express server
- npm run — runs the shell script helper

## Notes

The page is designed as a fun, personalized romantic experience and can be customized further by editing the content in index.html and the styling in the embedded CSS.
